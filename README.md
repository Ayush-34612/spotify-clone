# Spotify Clone - Web Player

A responsive web player UI clone of Spotify built with HTML and CSS. This project focuses on replicating the sidebar, main content area, and music player controls using Flexbox and CSS Grid.

## 🚀 Features
* **Responsive Design:** Hidden elements for smaller screens using Media Queries.
* **Modern UI:** Uses Montserrat font and FontAwesome icons for an authentic look.
* **Custom Scrollbars:** Styled to match the Spotify dark theme.
* **Interactive Elements:** Hover effects on cards and navigation items.

## 🛠️ Built With
* HTML5
* CSS3 (Flexbox/Grid)
* FontAwesome (Icons)
* Google Fonts (Montserrat)
